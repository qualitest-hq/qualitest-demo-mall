# C 端视觉预览扩充清单

针对 [c-end-ui-preview.html](./c-end-ui-preview.html)（衡物 · C 端机框原型）。  
**范围**：只改预览 HTML / 共享 JS·CSS 交互示意；**不**要求同期改 `/api`。  
前后端联合排期与 uni 约定见 [roadmap.md](./roadmap.md)。本预览增强批不阻塞联合主序。商家预览另见同仓 `merchant-ui-preview.html`。

按**小批次**落地：一次只盯一批，合入后再翻下一批。  
「状态」取值：未开始 / 进行中 / 已完成。  
**当前批次**：`C1`（改这里即可）。

---

## 1. 现状结论

主路径已闭环：登录（App / 小程序）→ 首页 / 分类 / 搜索 → 详情（SKU / 领券 / 运费）→ 购物车 → 结算 → 余额支付 → 订单 / 物流 / 退款 / 评价 → 我的（资料、改密、地址地图选点、券、余额提现、消息）。

缺口主要是两类：

1. **示意未闭环**：首页秒杀、详情收藏 / 分享、收银台仅余额等，点了只有 toast 或纯展位  
2. **常见辅助场景未做**：搜索排序、催发货 / 关单、评价筛选、领券中心、足迹等

不必一次做完；按下方 C1→C5 推进即可。积分 / 拼团 / 直播 / 真 IM 明确后置。

## 3. 明细清单

做某批时只扫该批行。「屏」指预览左侧 Tab 名或拟增屏 id。

### 3.1 C1 · 示意闭环

| 点 | 建议 | 屏 / 改动 | 状态 |
|---|---|---|---|
| 收藏列表 | 详情收藏写入列表；我的入口；可取消；下架灰显 | 新增 `favorites`；`fav` 落 state | 未开始 |
| 秒杀专场 | 首页秒杀进专场；倒计时、库存条、未开始 / 抢购中 / 已结束 | 新增 `seckill`；首页入口可点 | 未开始 |
| 分享面板 | 海报 / 链接 / 小程序码示意，确认后 toast | 详情 `⋯` 出 sheet | 未开始 |
| 多支付方式 | 收银台可选微信 / 支付宝 / 余额；余额不足仍引导充值；非余额可直接「支付成功」示意 | `pay` 改造 | 未开始 |

### 3.2 C2 · 逛购增强

| 点 | 建议 | 屏 / 改动 | 状态 |
|---|---|---|---|
| 搜索增强 | 历史、热搜、排序、有货筛选、空结果回分类 | `search` 加厚 | 未开始 |
| Banner | 轮播或点击进活动 / 券 / 商品 | `home` | 未开始 |
| 领券中心 | 店铺 / 品类 / 商品券汇总领取 | 新增 `couponCenter`；首页「领券」可改指此处 | 未开始 |

### 3.3 C3 · 订单与售后

| 点 | 建议 | 屏 / 改动 | 状态 |
|---|---|---|---|

## 4. 合入约定（预览）

每批合入前建议核对：

1. `SCREENS` / `renderers` / 左侧 `labels` / `SCREEN_NOTES` 同步  
2. 与商家端有联动的（订单、退款、评价、库存）仍走 `hengwu-preview-shared.js` 现有同步，不另起一套假数据  
3. App / 小程序切换行为若有差异，写进该屏 `SCREEN_NOTES`  
4. 不新增 README；进度只改本文「状态」与文首「当前批次」
